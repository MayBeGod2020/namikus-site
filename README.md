# Сайт Намикуса

Каталог шрифтов, песочница и статьи — на React + Vite.

## Что поменялось по сравнению со старым index.html

| | Было | Стало |
|---|---|---|
| Вес первой загрузки | 32 МБ (всё внутри одного HTML) | ~0,9 МБ |
| Шрифты превью | все ~550 файлов в base64, грузились разом | отдельные `.woff2`, качаются только для карточек на экране |
| Картинки статей | base64 внутри HTML | отдельные `.webp`, ленивая загрузка |
| Примеры использования | полноразмерные картинки 22×22 | миниатюры по 2–5 КБ, полные — только в просмотрщике |
| Песочница и статьи | всегда в HTML | грузятся отдельными кусками, когда их открывают |

Всё остальное — дизайн, фильтры, темы, лупа, песочница с глифами и языками, ссылки на разделы статей — работает как раньше. Старые ссылки вида `#guide/раздел` и `#sandbox/Имя` тоже работают.

## Запуск

Нужен [Node.js](https://nodejs.org) 20+.

```bash
npm install
npm run dev      # сайт для разработки: http://localhost:5173
npm run build    # готовый сайт в папке dist/
```

Папку `dist/` можно залить на любой хостинг как есть (GitHub Pages, Netlify, обычный хостинг) — в любую папку, пути относительные.

### Публикация на GitHub Pages

Сайт раздаётся из ветки `gh-pages`. После изменений:

```bash
git add -A && git commit -m "Что поменял" && git push
npm run deploy   # собирает сайт и выкладывает его в gh-pages
```

## Где что лежит

```
src/data/catalog.json    список шрифтов, фильтры, примеры использования
src/data/articles.json   статьи (блоки: h2/h3/p/ul/ol/img/cols)
src/data/previews.json   какие файлы превью у какого шрифта
public/pf/               шрифты превью (.woff2)
public/pfinfo/           списки знаков для вкладок «Глифы» и «Языки»
public/fonts/            zip-архивы шрифтов для скачивания
public/awards/           примеры использования (+ thumb/ — миниатюры)
public/art/              картинки статей
src/components/          компоненты страниц
src/styles/app.css       стили
```

## Как добавить шрифт

1. Сделать превью (нужен Python и `pip install fonttools brotli`):
   ```bash
   python scripts/add-preview.py a400 MyFont-Regular.ttf
   python scripts/add-preview.py a400 MyFont-Bold.ttf 700
   ```
2. Добавить строку в `src/data/catalog.json` → `fonts` (формат тот же, что был в index.html):
   ```json
   ["My Font", "Любой другой", ["Средний", "Диалоговый пузырь"], "n", 24, "ext",
    {"pf": "a400", "st": ["400n", "700n"], "u": "fonts/my-font.zip"}]
   ```
3. Положить архив в `public/fonts/my-font.zip` и запустить `npm run build`.
